# Speaker notes

An `<aside>` is a note for the speaker, which <kbd>S</kbd> shows in a window
of its own, along with what comes next, and a timer.

The notes of the slide: this one shows with the paragraph before it.

</aside>

- Each note shows with the element before it
- `step` places one anywhere, as `<aside step="3..">`

This one shows with the list.

</aside>

The timer counts down from the frontmatter's `duration`, or to its
`deadline`, and says when to speed up.
